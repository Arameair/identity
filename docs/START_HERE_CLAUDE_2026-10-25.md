## Owner-approved product direction (not another architecture debate)

- **Identity is the central registry and authority** for durable entity/service IDs, who they are, their stated capabilities, relationships, ownership and narrowly scoped grants. Every independent feature may have an Identity; a feature service identity is not the same as the entity using that service.
- **Each feature owns its work, process and data**. Identity does not perform thinking, ingest all logs, or become a universal runner. It starts independently without optional modules.
- **Thought Processor is the operational connection/testing workspace**: discovers services, displays truthful state, helps coordinate approved relationships, and exposes original application UI plus Logs / Flow / Metrics. It is not a second authority or mandatory transport for actual observations.
- **Thought Engine** performs thought processing and must enforce Identity-granted observation permissions at the actual receiver. Do not equate GitHub login, repository visibility, localhost port, launch consent or UI toggle with an Engine runtime grant.
- Intended end-user flow: `identity.exe` or `identity.sh` -> registered publisher GitHub App device login -> publisher feature catalog -> request access -> actual publisher approval -> verified install/start. Project Controller is **owner's development harness only**, not a dependency of the eventual user-facing product.
- The owner's requested normal **Identity UI is deliberately small**: verified status across top; persistent, live, scrollable event log as primary content; one-click **Copy Diagnostics** always accessible. Additional setup/account/permission views appear only when needed. Most ongoing monitoring should also be available in Thought Processor.
- Never fabricate green status, approvals, model output, installs, CI passes or end-to-end tests. Label `RUNNING`, `DISCOVERED / UNVERIFIED`, `AUTHENTICATED`, `AUTHORIZED`, `NOT CONFIGURED`, `BLOCKED` and `UNAVAILABLE` distinctly based on real evidence and timestamps.
