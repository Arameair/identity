Welcome to Identity

Identity keeps track of who is using your features and what they are allowed to do. This first setup takes a couple of minutes.

What this setup does

  • Connects your GitHub account through the publisher's GitHub App (you approve on github.com).
  • Shows the account and publisher information GitHub actually returns.
  • Lists the features and, honestly, what state each one is in.
  • Finds a Thought Processor running on this computer (read-only).

What it does not do yet

  • Send access requests to the publisher — drafts stay on this computer, not submitted.
  • Grant, install or start features.
  • Sign you in to Thought Processor — it has its own code.

Set up your own GitHub App — about 3 minutes

Only needed if this copy of Identity has no publisher app built in, or you're testing. It's free, and Identity never needs a password or a client secret.

  1. Open GitHub's "Register new GitHub App" page. The name, homepage and the one permission it needs are filled in for you.
    Open GitHub ↗
    If GitHub asks you to sign in first, do that — the page comes back afterwards.
  2. On that page, check these settings:
    • GitHub App name — replace YOUR-USERNAME with your own username; GitHub App names must be unique.
    • Callback URL — leave empty.
    • Enable Device Flow — tick this box. Sign-in won't work without it.
    • Webhook → Active — untick.
    • Repository permissions — leave everything at No access except Metadata: Read-only (GitHub sets that one automatically). Identity only needs to know who you are and which repositories you can see.
    • Where can this GitHub App be installed? — Any account (needed if other people will use this app).
  3. Click "Create GitHub App". On the page that opens, find Client ID (it starts with Iv) and copy it. Ignore "Generate a new client secret" — it isn't needed.
  4. Paste the Client ID here:
  5. Optional: on your app's page choose Install App and pick the repositories Identity should check. Installation is separate from device sign-in; a repository may still be invisible because it is private or the account lacks access.
